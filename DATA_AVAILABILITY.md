# Data availability

The public repository intentionally omits all source datasets and row-level records while redistribution permissions are pending.

Withheld inputs include the original and corrected 347-game reconstruction, frozen 68-program resource estimates, supplemental market-line records, archived comparison sheets and original source workbooks. Code references those private paths; they are not downloadable here.

The author reports sending two permission requests on October 1, 2026. No permission grant or organizer exception is claimed. Authorized data can be added in a future version after scope and conditions are checked.

The results directory contains aggregate outputs and recorded verification results from the complete private release. These are research outputs, not a substitute for source-data access.
